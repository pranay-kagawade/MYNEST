# MYNEST — My Personal Dashboard

**Your day. Your goals. Your space.**

MYNEST is a personal productivity web app that helps users to organize daily activities, manage tasks, track habits, take notes, and achieve their goals in one place.

## Direct link
https://personal-productivit-jgde.bolt.host/

## ✨ Features

- **Dashboard:** Personalized welcome and daily overview.
- **Notes:** Create and manage notes.
- **Tasks:** Add and track tasks.
- **Habits:** Build and track daily habits.
- **Focus Timer:** Improve concentration.
- **Planner:** Organize daily schedules.
- **Journal:** Record thoughts and experiences.
- **Goals:** Set and track personal goals.
- **Tools:** Access useful productivity tools.
- **Settings:** Manage app preferences.

## 🛠️ Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Database 

## 🚀 Getting Started

Make sure Node.js is installed, then run:

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal to use MYNEST.

To build the project for production:

```bash
npm run build
```

## 🔐 Data and Privacy

Data storage depends on the application's configuration. Cloud storage requires a properly configured database, while browser storage may keep data on the current device.
